## 3. 战斗规则（继承 v1.0 第 3 章，仅修订差异）

**继承不变**：60fps 固定逻辑帧、12 帧输入缓冲、四段连击数值（段 1~3 各 0.5s / 段 4 = 1.0s 重势）、闪避无敌帧（0.05~0.23s）、完美格挡 5 帧窗口弹刀、气槽规则（命中+3%/受击+2%/每秒+0.5%，技能 25%/大招 100%）、伤害公式与连击衰减（v1.0 §3.7）。

**v2.0 修订项**：
1. **键位定稿**（消除 v1.0 §5.3 教学章的矛盾写法）：

| 操作 | 键盘 | 手柄（Xbox 布局） |
|---|---|---|
| 移动 | A/D 或 ←/→ | 左摇杆 |
| 跳跃 | W / 空格 | A |
| 普攻（四段连按） | **J** | X |
| 闪避 | **K** | RB |
| 格挡（按住） | **L** | LB |
| 技能（25 气） | **U** | Y |
| 大招（100 气） | **I** | B |
| 暂停 | ESC（单按）/ 退出（双击确认） | Start |

2. **角色**：v1.0 §3.6 鼠行数据照用（HP 900 / 攻 95 / 防 80 / 移速 240），另加**暗鼠变体**：同数值、色相反转（暗金+深紫）、独立 AI 参数档；
3. **尺寸规格**：角色帧 **128×128**（修正 v1.0 的 64×64，以实际素材为准），锚点=脚底中心；
4. **羊"全队回血"措辞修正**：扩展库启用时改为自身回血（1v1 无队友）。
